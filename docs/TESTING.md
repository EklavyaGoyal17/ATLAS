# Testing strategy

Never substitute H2 for PostgreSQL when testing advisory locks, row locks, constraints, or Flyway migrations. `PaymentIntegrationTest` starts the application on a random port against an explicitly configured disposable PostgreSQL database. Maven fails rather than skipping integration tests when it is missing. Tests are not wrapped in a single test transaction: independent HTTP requests must commit and race through separate database connections.

The dedicated test database must be named `atlas_test`; test setup truncates its business tables only. Flyway initializes it first. CI provisions PostgreSQL 17. Tests verify migration presence, exact response replay after later mutations, concurrency, conflicting payloads, constraints, transaction rollback, authentication, API validation, per-currency reconciliation and persistence across a second application context. A fixed-seed generative loop exercises partial refunds and invariants.

Frontend: TypeScript compilation and Vite production build. Playwright drives the real console against the actual API for payments, systems, source, incident, design and growth workflows. Four explicitly labeled GitHub UI transport fixtures check consent/state with intercepted import responses; they do not claim real downloads. Actual anonymous GitHub import is checked separately by the operator smoke script. No dashboard measurements are invented.

`npm run test:unit` in `frontend` uses Node 24's built-in test runner and native TypeScript stripping to exercise the actual API helper. Seven checks cover ordinary and GitHub-specific deadlines, cancellation signals, authenticated payloads, idempotency headers and preserving server/network errors. Controlled signals avoid a 95-second wait. The GitHub browser fixture also observes the actual caller's signal deadline while preserving normal fetch/AbortSignal behavior. nginx gives only the exact GitHub import endpoint a 95-second upstream read-inactivity limit; ordinary API proxy reads remain at 15 seconds. The browser deadline applies to the overall request.
